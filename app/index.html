🏭 Image Factory Exemplar

This is a minimal example application demonstrating the Image Factory system.

About This Application

This simple nginx-based application is built and promoted through the Image Factory pipeline using:

  • Kargo - Orchestrates the build and promotion workflow
  • ArgoCD - Deploys the generated manifests
  • CDK8s - Generates Kubernetes resources from configuration

Image Details

Base Image: nginx:alpine

Repository: craigedmunds/image-factory-exemplar

Build Trigger: GitHub Actions workflow

If you're seeing this page, the Image Factory successfully built and deployed this application! 🎉
